## Features

- **Onboarding Experience**: Clean and welcoming entry screen.
- **Dashboard**:
  - Horizontal progress cards for habits/tasks.
  - "Today's plan" overview with progress visualization.
  - Custom bottom navigation bar (UI only).
- **Task Timeline**:
  - Detailed task list view grouped by time (Morning, After work, Bedtime).
  - Visualization of completed vs. pending tasks.
- **Modern UI/UX**:
  - Custom rounded design language.
  - Gentle green color scheme (`#00B074`).
  - Interactive elements and smooth transitions.

## Tech Stack

- **Framework**: Flutter
- **Language**: Dart
- **State Management**: Stateful/Stateless Widgets
- **Design Pattern**: MVC (Simple)

## Getting Started

### Prerequisites

- [Flutter SDK](https://flutter.dev/docs/get-started/install) installed on your machine.
- An IDE (VS Code, Android Studio, or Xcode).

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/yourusername/event_reminder_app.git
   cd event_reminder_app
   ```

2. **Install dependencies**
   ```bash
   flutter pub get
   ```

3. **Run the app**
   ```bash
   flutter run
   ```
